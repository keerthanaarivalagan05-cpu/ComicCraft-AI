# ComicCraft

ComicCraft is an AI-powered comic story creator.

It uses:

- FastAPI
- Jinja2
- Gemini
- Hugging Face image generation
- Pillow
- FPDF2
- Pydantic

## Workflow

User Input

↓

Gemini comic outline

↓

Five comic panels

↓

Gemini narration and dialogue

↓

AI image generation

↓

Comic layout

↓

PDF generation

↓

Comic preview

↓

Download PDF
